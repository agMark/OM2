The aileron-rudder interconnect system assists with turn coordination when the rudder or ailerons are used.

A stainless-steel cable attached to each rudder pedal is routed through a pulley system below the cockpit to each 180° aileron bellcrank. Each cable has a spring attached to the end below the cockpit. The interconnect system applies a force to the aileron controls as the rudder controls are manipulated. The interconnect system will also apply control forces to the rudder pedals when the aileron controls are manipulated.
