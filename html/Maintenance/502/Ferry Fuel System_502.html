The ferry fuel system utilizes the hopper as a temporary fuel tank and is not an FAA certificated fuel system. However, it may be installed for use during ferry flights provided a logbook entry is made for the installation and a ferry permit is granted by your airworthiness authority. When returning to the certificated configuration, a logbook entry must be made for removal.

Great care must be taken to ensure that the ferry fuel system is installed and removed properly and that contaminants are not introduced into the fuel system.

The ferry fuel system should be installed per Drawing 50280 Sheet 8 for AT-502B and AT-504 models and Drawing 50280 Sheet 9 for AT-502A models. The installation and removal of the ferry fuel system may be done in accordance with these drawings or in accordance with the instructions provided in this section which are provided here for convenience.

Installation of Ferry Fuel System (Ref Dwg 50280 Sht 8 or Sht 9)

  1. Ensure that hopper is completely empty, clean and dry before beginning installation.
  2. Remove existing cap from fuel valve and retain for reinstallation.
  3. If your aircraft is equipped withe the optional hopper rinse system, disconnect the hopper rinse line at the point that it enters the hopper or adapter. Install 50280-17 plug into end of hose running to hopper rinse pump.
  4. Install 51577-21 (for AT-502B and AT-504 models) or 51577-29 (for AT-502A models) hose on the fuel selector valve port that does not have a hose installed. Secure lines as required with cable ties. Do not tie off to E-Dump controls.
  5. Build up plug / adapter and pickup hose assembly.
      1. For AT-502B and AT-504 models, attach 51885-2 screen to 51886-4 pickup hose with a QS100M12S clamp.
      2. For AT-502A models, attach 51885-1 screen to 51886-1 pickup hose with a QS100M12S clamp.
      1. For aircraft with 2 inch bottom load, install flared fitting end of pickup hose onto internal end of nipple in the 53491-1 plug assembly.
      2. Install 80045-1 adapter hose over plug assembly and secure with two QS200M36S clamps.
      1. For aircraft with 3 inch bottom load, install flared fitting end of pickup hose onto internal end of nipple in the 51884-1 plug assembly.
      2. Install 80376-2 adapter hose over plug assembly and secure with two QS200M56S clamps.
  6. Install hopper / hose adapter and pickup hose & screen inside of the gatebox.
    1. Secure hose and screen with cable ties ten inches above the gatebox bottom.
      1. For aircraft with 2 inch bottom load, secure 80045-1 adapter hose onto gatebox tube with two QS200M36S clamps.
      2. For aircraft with 3 inch bottom load, secure 80376-2 adapter hose onto gatebox tube with two QS200M56S clamps.
  7. Connect supply hose from the hopper / hose adapter to the fuel valve routing through existing cutouts in the fuselage belly skins. Secure lines where required and able with cable ties.
  8. Mark fuel valve handle position for ferry fuel. Placard position depends on fuel valve type. For 502B-0600 and subsequent with AVI valve, install placard on cockpit side skin. Contact Air Tractor customer support otherwise.
  9. If desired, or required, install hopper lid fuel cap by cutting a 3.5 inch hole in the hopper lid and installing 416-3B-2 Adapter and 416-50 cap. Install the fuel cap by using the adapter as a guide to drill .257 holes through the hopper top. Install with 12 AN4C6A bolts, AN960C4 washers and MS21044C4 nuts. Install 416-50 retention chain between filler cap and bolt as shown. Seal all around inside of cap with fuel tank sealant.
  10. Coat all of the 80158 vent hoses and attaching clamps that are located inside the hopper with fuel tank sealant to prevent fuel from getting to the hoses.
  11. Seal hopper lid with fuel tank sealant.
  12. Allow all sealant to cure for at least 12 hours before flight.
  13. Test by filling hopper full and check for leaks after 30-45 minutes.
  14. Make a logbook entry stating that the ferry fuel system has been installed as a "TEMPORARY INSTALLATION FOR FERRY FLIGHT ONLY. MUST BE REMOVED BEFORE RESTRICTED OPERATION RESUMED."

Removal of Ferry Fuel System

  1. Turn fuel valve pointer to off position. Remove ferry fuel placard in cockpit.
  2. Remove hose and fitting at fuel valve and install plug. Cap and hole plug will be zip tied to hose from factory.
  3. Remove coupler, fittings, screen and filter from gatebox.
  4. Remove plug from bottom load tube opening in gatebox and install tube.
  5. Install spray pump, spray plumbing, and brake cable in reverse order of removal.
